# MiniRef — лёгкий многостраничный сайт

Готовый **статический HTML/CSS/JavaScript** без npm, React, внешних шрифтов, аналитических скриптов и сетевых запросов к сторонним ресурсам. Работает на GitHub Pages и любом обычном статическом хостинге.

## Что внутри

- `index.html` — выразительный лендинг, услуги, процесс, транспорт, география, FAQ и калькулятор параметров рейса.
- `services/` — каталог услуг.
- `services/refrigerated/` — рефрижераторные перевозки.
- `services/regular/` — регулярные поставки.
- `services/urgent/` — срочные перевозки.
- `services/retail/` — доставка в РЦ и сети.
- `fleet/` — автопарк.
- `process/` — как работаем.
- `about/` — компания.
- `contacts/` — контакты.
- `privacy/` — сведения о конфиденциальности.
- `assets/css/styles.css` — общая дизайн-система, анимации и адаптивность.
- `assets/js/main.js` — меню, анимации появления и формирование заявки.
- `assets/img/` — авторские SVG-заготовки, фавикон и OG-обложка.
- `settings.json`, `tools/build.py` — единые настройки и генерация страниц.

## Запуск

Откройте `index.html` в браузере. Для обычного локального сервера (рекомендуется):

```bash
python -m http.server 8000
```

Далее откройте `http://localhost:8000`.

## Перед публикацией — обязательно

1. **Подтвердите номер телефона**: `settings.json` содержит `+7 (977) 497-58-47` из раннего черновика MiniRef; в других черновиках встречался иной номер. Не публикуйте без сверки.
2. Проверьте фактическую доступность автопарка, заявленный диапазон `1–7 т`, температурные возможности, документацию и условия работы. На страницах сознательно нет придуманных тарифов, сроков подачи, отзывов и логотипов клиентов.
3. Добавьте настоящие фотографии собственных машин в секции-заготовки. Замените SVG-иллюстрации на оптимизированные WebP/AVIF при необходимости, сохранив `width`/`height`. Не используйте чужие фотографии без разрешения.
4. Укажите юридические реквизиты и подготовьте полноценную политику конфиденциальности по применимому законодательству, особенно если добавите форму, аналитические системы или cookies.
5. Укажите точный публичный URL в `settings.json`, поле `site_url` (например, `https://example.ru` **или** `https://grunt.github.io/miniref`), и пересоберите:

```bash
python tools/build.py
```

Это добавит **абсолютные canonical, OG URL и sitemap.xml**, а также инструкцию Sitemap в `robots.txt`. До настройки URL отсутствуют намеренно — недостоверные адреса вредят SEO.

## GitHub Pages

Создайте отдельный репозиторий, например `miniref`, чтобы не перезаписать существующий сайт на `grunt.github.io`. Загрузите **содержимое папки `miniref-site`** в корень новой репы. В Settings → Pages выберите `Deploy from a branch`, ветку `main`, папку `/ (root)`. URL будет похож на `https://grunt.github.io/miniref/`. Сначала впишите его в `settings.json`, выполните `python tools/build.py` и загрузите обновлённые файлы.

Все ссылки **относительные**, поэтому работают как на отдельном домене, так и в подпапке GitHub Pages.

## Как менять

- Общие цвета и размеры — переменные в начале `assets/css/styles.css`.
- Контакты и URL — `settings.json` + `python tools/build.py`.
- Контент, страницы и ссылки — `tools/build.py`; после правок выполнить команду сборки.
- Если меняете только CSS/JS — сборка не нужна.
- Калькулятор **не показывает цену** без утверждённых реальных тарифов и **не отправляет форму на сервер**. Он копирует параметры рейса в буфер обмена и предлагает позвонить.

## Производительность

Критический экран: встроенный в HTML `<img>` с `fetchpriority="high"`; остальные картинки `loading="lazy"`, имеют фиксированные размеры. Анимации сделаны на `transform/opacity`, без тяжёлых canvas/WebGL/видеофона. При `prefers-reduced-motion` анимации отключаются. Платных API, сторонних CDN и JavaScript-фреймворков нет.

**Не заявляем скорость или Lighthouse Score без измерений на реальном сервере и устройствах.** Нужны PageSpeed Insights / Search Console после выкладки.
